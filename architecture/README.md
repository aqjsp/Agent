# Agent 架构系列

只讲架构决策，不讲基础教程。Agent 是什么、Model 怎么调、Tool 怎么定义——这些在 [tutorial](../tutorial) 里。

这个系列回答一件事：**Agent 系统的架构怎么设计。** 每篇盯一个取舍，给选择依据，不给标准答案。
